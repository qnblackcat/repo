Hides the Shortcuts **"Running your automation"** notification, and the "N automations recently ran in the background" summary. Confirmation prompts ("Run" / "Don't Run") are kept.

Inspired by the "Disable Automation notifications" option in Powercuts, which stopped working on iOS 17. If you are on iOS 15-16, use [Powercuts](https://repo.anthopak.dev/) instead: it has more features and is confirmed to work reliably.
