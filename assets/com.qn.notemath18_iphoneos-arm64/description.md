Features:

* Type `=` after an expression and the result shows up right away. Press space or return to accept it (`1+1=2`).
* Results update live when you edit the expression, and also on undo/redo.
* Variables support: `a = 1`, `b = 3`, then `3a + 2b = 9` further down the note.
* iOS 18 style colours: correct results turn yellow, invalid expressions get a red mark.
* Tap a result to copy or cut it (iOS 16+).
