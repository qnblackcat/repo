0.4.0

New “Shift Delete” option in “Other Settings” (off by default): separate switches for Shift Hold + Delete and Shift Lock (Caps Lock) + Delete, which make Delete remove the word before the caret.

0.3.0

  • New "Other Settings" section in settings. All off by default:
    • Hide Paste Permission Alert: skips the "Allow Paste" prompt (iOS 16+). Based on NoPasteAlerts16 by 0xkuj.
    • Hide "Pasted from" Banner: removes the "X pasted from Y" notice after pasting. Based on NoPastedFrom by Brend0n.
    • Hide Keyboard Settings in 🌐 Menu: removes Keyboard Settings, Dictation Settings and the one-handed keyboard buttons from the globe key menu. Based on NoKeyboardSettings by Brend0n.
    • Replace Dictation with Hide Keyboard: replaces the mic below the keyboard with the hide keyboard button; hold it to dictate (Face ID iPhones only).
  • These options are based on NoPasteAlerts16, NoPastedFrom and NoKeyboardSettings, so FlicksForAll now conflicts with and replaces those tweaks.

0.2.3

  • Flicks now also work on the keyboard shown for Safari's address bar (the "AlphaWithURL" variant was previously skipped).
  • Each keyboard variant now keeps its own default layout, and a keyboard is only patched once.

0.2.2

  • Re-tuned Flick Sensitivity presets: they are now evenly spaced, and the lowest setting no longer makes flicks nearly impossible to trigger.
  • Settings: icons on each section, clearer descriptions (all settings below the test text field take effect immediately), copyright footer.

0.2.1

  • No longer requires Cephei: the settings pane now uses plain PreferenceLoader, so Cephei can be removed if nothing else needs it.

0.2.0

  • Fixed settings not applying in sandboxed apps (Messages, Music, App Store apps…). Settings are now stored in a file inside jbroot instead of going through cfprefsd; existing settings are migrated automatically.
  • Fixed flick symbols disappearing when the Symbol Size was set too small.

0.1.8

New Flick Sensitivity presets (5 levels), haptic strength options and optional Feedback on Cancel, Symbol Size presets, export/import presets, reorganised settings with clearer descriptions, new settings icon

0.1.5

Better logic distinguishes between flick and slide to type; fix preview glitch

0.1.4

  • Dropped iOS 12/13 support, code cleanup.

0.1.3

  • Fixed the character preview flickering while flicking.

0.1.2

  • Roothide build.
  • Extra-light haptic option, smaller symbols by default.
