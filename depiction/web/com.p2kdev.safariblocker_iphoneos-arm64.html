Tweaks

1.3.5

  • Tabs you open yourself (e.g. SafariPicker's "Open in Private/Normal Mode") are no longer blocked; web pop-ups are still checked.
  • New Source Code section in settings.

1.3.4

  • New (Experimental): Stop Blocked Pop-ups Loading. Blocked pop-ups no longer load in the background, so they don't show up in History. While the SafariBlocker alert is open the pop-up is held; "Allow once" releases it.
  • Downsides of the option: an allowed pop-up only starts loading after you tap "Allow once" and may open blank or fail (e.g. some sign-in or payment pop-ups). It relies on private Safari internals that may change between iOS versions. Off by default.
  • Internal cleanup of the blocking logic.

1.3.3

  • Safari no longer crashes if Apple renames one of its internal properties; SafariBlocker just skips that step.
  • Malformed allowed/blocked lists in preferences are ignored instead of crashing.
  • Rootless dependency removed: native roothide build, no rootless-compat needed.

1.3.2

  • Fixed domain and URL matching: only the leading https://, http://, // and www. are stripped now, so blocked/allowed lists match correctly.
  • Fixed a crash when reading the parent tab on iOS versions where Safari no longer has that field.
  • Only one SafariBlocker alert is shown at a time; extra pop-ups that arrive while it is open are blocked (with a toast if enabled).
  • The alert is presented from the topmost screen, so it shows even when something else is already open.

1.3.1

  • iOS 15+ support for rootless and roothide jailbreaks.

1.2

  • Fixed SafariBlocker blocking the "Open in New Tab" action.
  • iPad improvements.
  • Thanks to opa334 for the above changes.

1.1.1

  • Added option to disable the blocked message.
  • Exception handling for some crashes users were experiencing.

1.1

  • Initial release by P2KDev: control pop-ups and new tabs opening automatically in Safari.
