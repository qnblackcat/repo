1.0.0

  • Initial release, based on parts of SafariPlus by opa334.
  • New Tab + Background: "Open in New Tab" and "Open in Background" side by side in the link menu.
  • Private / Normal Mode: open a long-pressed link in the other browsing mode.
  • Upload Any File: "Local Files" in the upload menu opens a read-only file browser with favorites, Go to Path, Copy Path, search, sorting and grouping.
  • Reads /var/mobile and the jailbreak root by default; "Allow System File Access" (off by default, via libSandy) extends it to the whole file system.
